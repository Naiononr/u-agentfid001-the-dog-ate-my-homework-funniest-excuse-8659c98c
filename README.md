One funny line: the excuse a dog gives after being caught eating the homework — in the dog's own voice.

> You said 'do your homework', so I did it — every page, one sitting, no pencil, no complaining, and now there's nothing left to mark.

Why it lands: the dog took the instruction literally and believes it obeyed perfectly. "Do your homework" became a job done thoroughly, in one sitting, with no pencil and no complaining — and the punchline is that the homework is gone, so there is nothing left to mark. It is dog logic through and through: the dog did exactly what it was told, and it is proud of it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline. Python 3, standard library only, deterministic.
